### 💡 About Me

I'm **Raffata Izacky Yuargya Aletama** (you can call me **Raffata** or **Raff**), an undergraduate **Information Systems** student at the **Faculty of Industrial Engineering, Telkom University Jakarta** (Class `S1-SI-KJ-25-02`). I spend my time building coursework projects with **Laravel**, **PHP**, **Java**, **Python**, and **C#**, experimenting with **Docker** and **Linux**, and designing information systems using **UML & BPMN**.

- 🔭 **Currently building:** Multi-role web applications for coursework & lab practicums in **Laravel 12** (RBAC, file storage, REST APIs, and PHPUnit testing).
- 🌱 **Currently learning:** Dockerized backend environments, Linux administration (Rocky Linux, SSH/SELinux, Bash scripting), and UI/UX usability engineering.
- 🎓 **Academic focus:** **Web Application Development (PAW)**, **System Analysis & Design (APSI)**, **Business Process Modeling (PPB)**, **Industrial Statistics**, and **Operating Systems**.
- 🤝 **Looking to collaborate on:** Campus team projects, study groups, and hands-on web, bot, or system modeling builds.
- ⚡ **Fun fact:** I enjoy debugging stubborn server configs (from `sshd` ports to Docker MySQL mappings) almost as much as shipping clean commits.
